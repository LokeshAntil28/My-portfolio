## 📋 Project Details

### 🌤️ 1. WeatherNow
**Description:** A responsive weather dashboard that shows real-time weather data for any city. Features city search, auto-location detection, current conditions (temp, humidity, wind, pressure, visibility), and a 5-day forecast.

**Key Concepts:** Async/await, Fetch API, JSON parsing, Geolocation API, localStorage caching
**API Required:** Free key from openweathermap.org
**Files:** `index.html`, `style.css`, `app.js`

---

### 💰 2. BudgetTracker
**Description:** A personal finance tracker to log income and expenses by category and date. Includes live summary cards, a doughnut chart by category, a monthly bar chart, transaction history with filtering, and CSV export.

**Key Concepts:** DOM manipulation, Chart.js, data aggregation, CSV Blob export, localStorage CRUD
**Files:** `index.html`, `style.css`, `app.js`

---

### ✅ 3. TaskFlow
**Description:** A Kanban-style task manager with three columns (To Do, In Progress, Done). Cards support drag-and-drop between columns, priority badges (Low/Medium/High), due dates with overdue detection, and a modal form for adding/editing.

**Key Concepts:** Drag & Drop API, modal UI, localStorage CRUD, conditional styling
**Files:** `index.html`, `style.css`, `app.js`

---

### 🛒 4. ShopEase
**Description:** A fully functional e-commerce frontend with 12 products across 5 categories. Features real-time search, category filter, sort by price/rating, slide-in cart sidebar, quantity controls, live cart total, and a checkout confirmation flow.

**Key Concepts:** Array filter/sort, localStorage cart state, slide-in sidebar, dynamic rendering
**Files:** `index.html` (self-contained)

---

### 💬 5. ChatBuddy
**Description:** A chat application UI with a join screen (username + room), message bubbles, online user sidebar, typing indicator, and simulated bot activity. Designed as a frontend demo — includes detailed instructions to connect a Socket.io backend.

**Key Concepts:** DOM-based SPA, color generation, event handling, real-time UI patterns
**Files:** `index.html` (self-contained)

---

### ✍️ 6. BlogSpace
**Description:** A blogging platform with a post card feed, tag filtering, real-time search, full post reading view, and a write/publish form. Comes with 5 pre-loaded developer blog posts and supports creating new posts that persist via localStorage.

**Key Concepts:** SPA view routing, localStorage CRUD, tag system, content rendering
**Files:** `index.html` (self-contained)
